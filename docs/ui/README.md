## 图层怎么读

图层名形如 `分区 / 元素  @token@`，`@token@` 就是代码里 `theme.py` 的变量名。
改哪一层，就等于改哪个 token / 哪个控件；不需要改图层名，只要在 PSD 里保留它。

```
01 background        背景（窗口底色 / 32px 网格 / 四角晶体）
02 topbar            菜单栏、工具栏、品牌铭牌、斜切按钮、服务器选择
03 file-list-panel   左侧列表面板（切角框、搜索框、下拉框、列表行、选中态）
04 detail-panel      详情面板（切角框、模块区边框、图标格子、三张卡片）
05 art-slot-reserved 立绘预留位（虚线框——这里放角色插画）
06 log-panel         底部日志面板
07 statusbar         状态栏
```

## 造型约定（改的时候请保持）

- **普通控件用圆角**：输入框 / 下拉框 / 普通按钮 4px、复选框 3px、表格与分组框 6px、
  滑条轨道 2px、滑块 6px、进度条 7px、滚动条滑块 4px。
- **结构件用切角**：面板、对话框、工具栏按钮是 45° 切角（不是圆角）；两者不要混用。
- **装饰不进正文**：网格 / 光带 / 晶体只允许出现在背景层与面板底，不能压到文字和数值上。
- **图标格子保持深底**：舰长技能、升级品等图标是白色单色图形，格子底必须在深浅主题下都偏深。
- **立绘预留位**：只占空间、不放程序自带的图；插画素材由使用者自行准备。

## 重新生成

配色或布局改动后，可以重新导出：

```powershell
pip install psd-tools
.venv\Scripts\python.exe scripts\gen_ui_psd.py
```

脚本读取 `utils/theme.py` 的实际色板，所以生成出来的 PSD 永远与代码同步。

## 回填流程

1. 在 PSD 里调整颜色 / 线宽 / 圆角 / 间距；
2. 保存并交回 PSD（或直接说明「哪层改成什么」）；
3. 按图层对应关系改 `utils/theme.py`（颜色）或 `resources/styles/main.qss` / 自绘控件（线宽、圆角、间距）；
4. 重新生成 PSD 与截图，与你的版本逐层比对。
