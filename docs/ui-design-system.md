# UI 设计系统

本文记录当前界面的设计语言、主题架构与实现约定。修改界面前请同时阅读 [AGENTS.md](../AGENTS.md)。

---

## 1. 设计基调

界面以「**光线 + 切角结构**」为主体：面板由细线轮廓、切角、局部辉光与光学定位标记构成，正文与数据始终以可读性优先。

优先级固定为：**功能正确性 > 信息可读性 > 操作效率 > 视觉效果**。

- 光线是主体，实体是辅助；
- 晶体/切角只出现在面板与关键入口，不进正文区；
- 信息优先：任何装饰都不得覆盖或削弱数据；
- 所有颜色集中管理，禁止逐控件硬编码。

## 2. 主题架构

### 2.1 两层正交

```
主题 = 深浅模式（auto / light / dark）  ×  角色皮肤（SKINS，可空）
```

- **深浅模式**决定明暗；`auto` 跟随 Windows 深浅色。
- **角色皮肤**接管整份调色板（因此启用皮肤时 `theme.dark == False`），并提供自己的装饰语言。
- 两者都在 `utils/theme.py` 的 `_Theme` 单例里落地，对外暴露：`theme.mode`、`theme.dark`、`theme.skin`、`theme.palette_name()`。

### 2.2 调色板

| 调色板 | 定位 | 主信号色 |
|---|---|---|
| `_LIGHT` | 浅色：白底 + 浅蓝光线 | `#2E6FB0` |
| `_DARK` | 深色：深海军蓝 + 冰蓝光线 | `#4FD8F2` |
| `_SKIN_CYRENE` | 角色皮肤·昔涟：白底 + 樱粉 | `#C2557C` |

三套调色板的 **key 集合必须完全一致**（当前各 83 个 token）。新增 token 必须同时加到所有调色板里。

### 2.3 皮肤注册表

```python
SKINS = {
    "cyrene": SkinSpec(
        id="cyrene",
        name="昔涟（半成品）",
        palette=_SKIN_CYRENE,   # 只有配色
    ),
}
```

**新增一套角色配色**：

1. 在 `utils/theme.py` 加一份完整调色板字典（token 数与 `_LIGHT` 一致）；
2. 在 `SKINS` 里注册一条（需要主界面留立绘位时加 `art_slot=True`）；
3. 设置界面的下拉由 `skin_ids()` 自动生成，无需改动其它代码。

**发布版不可选用**：`skin_ids()` 只在源码/调试运行（`utils.path_utils.is_debug_build()`）时返回皮肤 id；Nuitka 编译的发布版返回空元组，下拉里只有 auto/light/dark，配置文件里残留皮肤 id 也会被 `get_skin()` 判为不可用并回落到普通深浅色。

**角色配色只改颜色**：历史上做过的背景水印、纹样列、自绘立绘均已删除。现在唯一保留的结构性差异是 `art_slot` 立绘预留位——只占横向空间、画一圈虚线框提示「这里放插画」，不含任何内容，也不会盖住数据。

## 3. 组件层

| 组件 | 文件 | 职责 |
|---|---|---|
| `HoloBackdrop` | `ui/widgets/scifi_panel.py` | 工作区背景：底色、网格、斜向冷光带、外框（无角落装饰、无皮肤水印） |
| `SciFiPanel` | 同上 | 切角面板：半透明底、外辉光、1px 轮廓、切角描亮、左缘锚点、刻度 |
| `ScanStrip` | 同上 | 状态栏任务扫描光线 |
| `CrystalMark` / `SparkDot` | 同上 | 品牌棱晶标识 / 点缀光点（皮肤可换形态） |
| `SciFiButton` | `ui/widgets/scifi_button.py` | 斜切薄片按钮（工具栏专用） |
| `HoloDialog` / `HoloWindow` | `ui/widgets/dialog_style.py` | 带切角外框的对话框 / 独立工具窗口基类 |
| `SkinArtSlot` | `ui/widgets/skin_art.py` | 角色主题右侧的**立绘预留位**（只占空间与画虚线框，不含任何内容） |
| `PartsTreePanel` | `ui/widgets/parts_tree.py` | 两个 3D 查看器左侧的**模型部件纵列**：按分组列出全部渲染网格，逐条勾选显隐（一对一绑定网格 key）；行内第一行是**形状 / 模型名**、第二行是**顶点格式串**（自绘 delegate 按宽度换行，无横向滚动条） |

自绘控件统一在 `bus.theme_changed` 时清缓存并重绘。

## 4. 造型规则

### 4.1 圆角 vs 切角

| 类别 | 造型 | 实现位置 |
|---|---|---|
| 滑条轨道/滑块 | 圆角 2px / 6px | `main.qss` |
| 输入框、下拉框、数值框 | 圆角 4px | `main.qss` |
| 普通按钮 `QPushButton` | 圆角 4px | `main.qss` |
| 复选框指示器 | 圆角 3px | `main.qss` |
| 分组框、表格、菜单、Tab 面板 | 圆角 6px | `main.qss` |
| 进度条 | 轨道 7px / 进度段 6px | `main.qss` |
| 滚动条滑块 | 圆角 4px | `main.qss` |
| 面板、对话框、工具栏按钮 | **切角 / 斜切**（特殊造型） | `SciFiPanel` / `HoloDialog` / `SciFiButton` |

判定标准：**是不是"光学结构"的一部分**。不是 → 圆角。

### 4.2 装饰分层（硬规则）

```
HoloBackdrop 背景层        ← 网格、光带（所有主题一致，四角留空）
  └─ SciFiPanel 面板底     ← 半透明切角底 + 轮廓 + 辉光
       └─ 业务控件          ← 文字、表格、图标，全部不透明前景
```

- 装饰**只能**出现在背景层与面板底，不得置于业务内容之上；
- 面板/卡片允许半透明（让底纹透一点出来），但文字与其底色保持不透明；
- 角色主题只引入配色差异，外加一个**空的立绘预留位**（只占空间、不画内容）；
- 例外：舰长技能 / 舰船配件等**白色单色图标**的格子需要深色底叠加以保证对比度。

### 4.4 版式 PSD

`docs/ui/main-window-*.psd` 是从代码渲染导出的分层版式，图层名 `分区 / 元素  @token@`。
需要人工调样式时在 PS 里改这些图层，再把改动回填到 `theme.py` / `main.qss` / 自绘控件。
详见 [ui/README.md](ui/README.md)。

## 5. 关键 token

| token | 用途 |
|---|---|
| `window_bg` / `panel_bg` / `panel_alt` | 三级背景 |
| `panel_fill` / `panel_fill_soft` / `card_bg` | 面板与卡片的（半透明）填充 |
| `panel_frame` / `panel_frame_hi` | 面板轮廓（常态 / 强调） |
| `accent` / `accent_hi` / `on_accent` | 主信号色（焦点、选中、主操作） |
| `accent_warm` | 关键数值、非选中炮塔点等暖色强调 |
| `value_pos` / `value_neg` | 属性增减值 |
| `icon_btn_*` | 图标格子（深底 + 亮边，两套主题都保持深色） |
| `grid` / `hud` / `holo_ice` / `holo_glow` | 网格与全息装饰 |
| `crystal` / `crystal_edge` | 晶体折射与棱线 |
| `gold*` | 强化/传奇技能等特殊标记 |

## 6. 无障碍与可用性

- 正文与背景对比遵循 WCAG AA（≥ 4.5:1）；白图标在图标格子上 ≥ 9:1。
- 状态不能只靠颜色表达，必须同时有文字/图标。
- 全息效果恒为开启，不提供关闭入口；半透明只作用于背景层，正文与数值始终不透明。
- 动画只用于反馈（悬停、选中、进度），不做持续闪烁与大面积扫描。
- 保留全部键盘操作：Tab 导航、快捷键、复制粘贴、右键菜单。
